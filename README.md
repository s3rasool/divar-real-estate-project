## 🔄 آخرین تغییرات و وضعیت پروژه (Recent Progress)

### ۱. یکپارچه‌سازی و ایجاد نوت‌بوک اصلی (`main_pipeline.ipynb`)

* **ارزش کل مالی / رهن کامل (`inferred_full_credit_amount`):** بر اساس منطق عرف بازار (فرمول تبدیل اجاره به رهن کامل)، یک ستون عددی اختصاصی ساخته شد تا در مدل‌سازی‌های عددی و خوشه‌بندی استفاده شود.
* **ستون‌های باینری/امکانات:** مقادیر مفقوده (`NaN`) در ویژگی‌هایی مثل آسانسور، پارکینگ، بالکن و انباری با `False` جایگزین و نوع داده‌ای آن‌ها یکدست شد.
* **مختصات جغرافیایی:** ستون‌های UTM جهت محاسبات متری مکان‌پایه کاملاً استاندارد شدند.
